Premiere Pro 导入说明
=====================

文件
----
ngnl_amv_v20.xml     Final Cut Pro 7 XML（Premiere 可直接导入）
song_1794608919.flac 音轨源文件

导入步骤
--------
1. 把 song_1794608919.flac 放到 D:\ngnl_amv\  （XML 里写的就是这个路径）
   放在别处也行，导入后右键素材「链接媒体」重新指向即可。
2. Premiere → 文件 → 导入 → 选 ngnl_amv_v20.xml
   会自动建立一个 1920x1080 / 24fps 的序列，25 个片段 + 1 条音轨。
3. 源视频路径写的是：
   D:\bitcomet download\[VCB-Studio] No Game No Life Zero [Ma10p_1080p]\
   [VCB-Studio] No Game No Life Zero [Ma10p_1080p][x265_flac].mkv
   路径不同的话会弹「链接媒体」，指到那个 mkv 即可。

序列结构
--------
- 视频轨：25 个片段，按成片顺序排列，每段都带正确的源入点/出点
- 音频轨：整首歌从 0 秒开始
- 标记：每个剪辑点一个标记，注释里是该段的剧情说明

与成片的差异
------------
成片里每段之间是 0.5 秒交叉溶解，片段有重叠；XML 里为了便于在 PR 里改，
把重叠折算掉了，片段首尾相接但**剪切点位置完全一致**，总长仍是 178.0 秒。
想要溶解的话，在每两个相邻片段之间加「交叉溶解」即可。

媒体帧率说明
------------
源片是 23.976fps，序列与 XML 按 24fps 写。178 秒累计误差约 0.18 秒，
肉眼不可见；若要求帧级精确，导入后在序列设置里把时基改成 23.976。
